⚙️ Settings — API Key Video AI

Tempel API key kamu sendiri per provider. Kalau satu provider mati, tinggal ganti provider aktif — atau nyalakan fallback otomatis.

⚠️ Mode demo — backend belum terhubung. Pengaturan di sini hanya simulasi: key tidak disimpan dan generate memakai video contoh.
🔒 Key disimpan terenkripsi (AES-256-GCM) di server, satu key per provider, terikat akun Telegram kamu. Key utuh tidak pernah dikirim balik ke aplikasi, tidak pernah tampil penuh, dan tidak pernah ditulis ke log. Kolom tempel key selalu kosong saat halaman dibuka.

⚠️ Jangan bagikan API key kamu ke orang lain — key itu terhubung ke tagihan akun AI kamu.
